Сидел тут вечером ковырял проект на MAUI, и как же глупо создаются пакеты MSIX и система обновлений пакета публикации, но не об этом.

Бывает нужен современный дизайн программы а писать на MAUI, так не прост в освоении.
Всякие Guna Metro и подобные фреймворки не дают такого дизайна, и зачастую какой-нибудь issue висит не закрытый пару лет с проблемой Label.
Wpf? писать дизайн на Wpf нууууу, я бы за такое не взялся.
Есть ELECTRON.NET но нам мультиплатформенное приложение не нужно.

Моя задача была в том, чтобы быстро написать приложение для Windows с современным адаптивным дизайном.
Winforms вполне годно, но вот не хватает в нём анимашек и эффектов всяких, а писать дополнительно к рендеру отрисовки или использовать не GDI слишком усложняет задачу и растягивает срок, да и проблемы с двойной буферизацией когда дело доходит для Transparent.

Выбрал я значит использовать подход рендера html с js. Как рендерить?
WebView2.
Минусы конечно есть + Огромный размер файлов библиотек, но дизайн наше всё.

Нужно конечно разбираться не только c# в но и базово в html + css , но Bootstrap половину проблем решает.

Подключаем библиотеку кидаем WebView на форму и немого покодим.

private async void InitializeWebView()
 {
     await webView21.EnsureCoreWebView2Async();
     // Загрузим локальный HTML-файл
     string htmlPath = Path.Combine(AppDomain.CurrentDomain.BaseDirectory, "index.html");
     webView21.CoreWebView2.Navigate(htmlPath);
 
     // Регистрируем объект C# для взаимодействия с JavaScript
     webView21.CoreWebView2.AddHostObjectToScript("myCsharpObject", new MyCsharpObject());
 }
 
  private async void тёмнаяТемаToolStripMenuItem1_Click(object sender, EventArgs e)
  {
      var currentTheme = await webView21.CoreWebView2.ExecuteScriptAsync("document.documentElement.getAttribute('data-bs-theme');");
      currentTheme = currentTheme.Trim('"');
 
      string newTheme = "dark";
      await webView21.CoreWebView2.ExecuteScriptAsync($"document.documentElement.setAttribute('data-bs-theme', '{newTheme}');");
  }
 
  private async void светлаяТемаToolStripMenuItem_Click(object sender, EventArgs e)
  {
      var currentTheme = await webView21.CoreWebView2.ExecuteScriptAsync("document.documentElement.getAttribute('data-bs-theme');");
      currentTheme = currentTheme.Trim('"');
 
      string newTheme = "light";
      await webView21.CoreWebView2.ExecuteScriptAsync($"document.documentElement.setAttribute('data-bs-theme', '{newTheme}');");
  }
